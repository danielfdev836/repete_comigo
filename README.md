# 🗣️ Repita Comigo

Site informativo sobre **fonoaudiologia**: o que é a área, por que ela é importante, quais cuidados ajudam a fala, a voz e a audição e quando procurar um profissional.

Projeto final da disciplina de **Desenvolvimento Front-end para Web** (Ciência da Computação), feito com HTML, CSS e JavaScript puros.

> **Tema:** Saúde, Educação e Inclusão

---

## Autores

- **Daniel Fernandes Canuto**
- **Francisco José Alvarenga Santos**

---

## Objetivo

Muita gente não sabe o que a fonoaudiologia faz nem quando buscá-la. O site reúne essa informação em páginas curtas, em português e de leitura simples, para ajudar famílias, estudantes e qualquer pessoa interessada no assunto.

>  O conteúdo é **informativo** e não substitui a avaliação de um profissional de saúde.

---

## Páginas

| Página | Conteúdo |
|---|---|
| `menu.html` | Página inicial, com o topo do site e atalhos para as demais páginas |
| `o-que-e.html` | O que é a fonoaudiologia e suas áreas de atuação |
| `importancia.html` | Por que ela é importante em cada fase da vida |
| `por-que-agora.html` | Por que a área recebe mais atenção atualmente |
| `cuidados.html` | Cuidados do dia a dia com a fala, a voz e a audição |
| `sinais.html` | Sinais de alerta e quando procurar um profissional |
| `duvidas.html` | Perguntas frequentes |

---

## Funcionalidades

- Layout **responsivo**, que se adapta a computador e celular
- **Modo claro e modo escuro**, trocados por um botão no menu
- Perguntas frequentes que **abrem e fecham**
- Cartões com imagens e textos explicativos
- Ano do rodapé atualizado automaticamente

---

## Tecnologias

- **HTML5**: estrutura das páginas
- **CSS3**: estilo, cores, flexbox e modo escuro
- **JavaScript**: interações simples (tema e rodapé)
- **Git e GitHub**: versionamento e trabalho em dupla

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/danielfdev836/repete_comigo.git
   ```
2. Abra a pasta no **VS Code**.
3. Abra o arquivo `HTMLS/menu.html` com a extensão **Live Server** (botão "Go Live"), ou dê dois cliques no arquivo para abri-lo no navegador.

Não é preciso instalar nada nem ter conexão com banco de dados.
